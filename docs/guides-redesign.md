## 바뀌는 것 / 그대로인 것 (모든 페이지 공통)
- 바뀜: 배치·디자인(guide-c 틀), 폰에서 섹션 펼침, 섹션 바로가기 칩, 첫 화면 답 카드(페이지마다 기존 데이터로).
- 그대로: 주소, 검색 제목·설명(`layout.js(x)` 수정 안 함), H1, H2 문구, 섹션 id, 구조화 데이터, 조회수 기록(`GuideViewTracker`), 체크리스트 저장 키.

## 디자인에서 달라진 구조 (공통 외)
- /visa: E-9·D-2·D-4 탭 → 각자 섹션(H2 = 비자 이름, id `visa-e9` 등 그대로). 첫 섹션은 비자 3장 답 카드.
- /korean-life: 일상/직장 표현 탭 → 섹션 2개(`kl-daily`, `kl-work` — H2 추가). 접힌 "오해" 목록은 펼침.
- /hospital: 상황별 안내 접힘 → 펼침. 맨 위 고정 응급 띠 → 첫 섹션 전화 카드.
- /emergency: 맨 위 119·112 띠 → 첫 섹션 큰 전화 카드. 연락처 카드는 새 부품(번호 버튼·운영시간·몽골어 가능).
- /arrival: 1~2일 / 3~7일 / 2~4주 체크리스트를 데스크톱에서 한 줄에 나란히(첫 화면 답).
- /transport: 첫 섹션 맨 위에 기본요금 3개(지하철·버스·택시) 큰 숫자.
- /apps: 앱 카드는 카드 전체가 Play Store(없으면 웹사이트) 링크. "관련 가이드" 묶음에 id `apps-related` 부여.
- 모든 페이지: 마스코트 그림 → 홈 장면 그림+루프 영상, 아이콘 이모지 제거.
- 안 쓰게 된 옛 파일 7개 삭제(2026-10-27, 사용자: "안쓰는 파일 삭제"): `src/app/visa/VisaTabs.jsx`·`visa.module.css`, `src/app/arrival/arrival.module.css`, `src/app/emergency/emergency.module.css`, `src/app/apps/apps.module.css`, `src/app/korean-life/KoreanLifeTabs.jsx`·`korean-life.module.css`.
