# 2026-09-16 디자인·사용성 개선 기록

9월 15일 디자인 적용 이후 사용자 화면 피드백을 반영한 후속 작업이다.

## 완료 내용

- **표·모바일 안내:** 표 제목 대비 개선, 가로 스크롤바 유지, 별도 슬라이더 제거. 공통 안내 섹션을 모바일 아코디언으로 구성하고 펼침·접힘 모션 및 목차·해시 이동을 연결했다.
- **화면 너비:** 안내 탐색 영역의 최소 너비 때문에 생기던 가로 넘침과 모바일 오른쪽 빈 띠를 수정했다. 모달 열림 시 스크롤바 공간이 중복되는 문제도 정리했다.
- **모바일 메뉴:** 상위·하위·단일 메뉴의 위계를 구분하고 상위 그룹 접기, 아이콘, 현재 위치 표시를 적용했다. 사용자 피드백에 따라 과한 장식을 줄였다.
- **경로 탐색:** 현재 단계와 상위 단계에서 같은 수준의 경로를 선택하는 메뉴를 제공한다. 바깥 클릭·Escape·경로 변경 시 닫힘을 처리했다.
- **문의·정보 수정 모달:** 공통 디자인, 내부 스크롤, 포커스 및 작은 화면 배치를 개선했다. 관련 버튼의 호버 대비와 공유 버튼의 클릭 영역·외형도 보완했다.
- **후원:** 안내 배너와 주요 버튼의 주목도를 높이고 후원 페이지의 카드·결제 링크를 정돈했다.
- **소개·빠른 답변 상세:** 공통 색상과 타이포그래피에 맞춰 소개 페이지와 `/tips/[slug]`의 본문·안내 영역을 정리했다.
- **커뮤니티:** 첫 화면의 게시판 안내, 목록·상세·글쓰기 디자인을 정리하고 댓글·게시글 동작의 사용자 문구를 몽골어로 맞췄다.
- **문의 `/contact`:** 유형별 색상 아이콘과 선택 상태, 작성 폼 제목·코랄 포인트, 이메일·답변 안내 영역을 적용했다. 모바일에서는 작성 폼을 먼저 보여준다.
- **푸터:** 글자 대비, 링크 터치 영역, 모바일 열 배치를 개선했다.

## 검증과 범위

- 작업별 JSX SWC 문법 검사, CSS PostCSS 구문 검사 및 Git diff 공백 검사를 수행했다.
- 사용자 승인 아래 기존 `localhost:5005`에서 PC·모바일 화면과 관련 상호작용을 확인했다. 문의 페이지는 320·390·1280px에서 가로 넘침 없이 유형 선택·입력을 확인했다.
- 커뮤니티의 일부 상세·작성 상태는 테스트용 응답으로 확인했다. 실제 문의 전송·글 등록·결제는 수행하지 않았다.
- 전체 빌드와 서버 실행·종료·재시작은 수행하지 않았다. 정보 내용의 법률·의료·비자 최신성 검증은 포함하지 않았다.
- 인증·백엔드·DB·의존성 변경은 없으며, 마이페이지·약관·개인정보 화면은 이번 개선에서 제외했다.
- 임시 검증 스크립트와 화면 캡처(`tmp/`)는 커밋에서 제외한다.

이 기록은 `design-work-2026-09-15.md`의 미착수 후보 중 이번에 완료한 부분을 보완한다.
