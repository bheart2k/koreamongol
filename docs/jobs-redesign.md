# /jobs 새 디자인 적용 — 기준선과 배포 기록

> 원칙: 블루밍하트 저장소 `docs/사이트개편-단계-측정-원칙.md` §2 "한 페이지를 처음부터 다시 짜는 개편은 그 페이지 하나만 바뀌는 배포로 묶어도 된다" — 주소·제목·설명·H1은 그대로, 다른 페이지 변경·측정 코드 변경과 섞지 않는다.
> 사용자 결정(2026-10-27): "5번도 디자인 하자." (5번 = 제안 "다음 새 디자인은 /jobs")

## 바뀌는 것
- 화면 배치·디자인: /topik과 같은 틀(`src/components/guide-c/`). 데스크톱 2단, 첫 화면에 "누구냐(E-9 / 학생)" 답 카드, 섹션 바로가기 칩, 머리 그림(홈 일터 장면 루프 영상 `c4-work`).
- 폰: 섹션이 접히지 않고 모두 펼쳐짐(지금은 섹션마다 눌러야 열림).
- 체크리스트 2개(계약서·일용직)는 새 디자인으로 바꾸되 저장 키(`guide-check-jobs-contract`, `guide-check-jobs-daily-before`)는 그대로 — 전에 체크한 상태가 이어진다.
- 새 틀에 없던 부품 추가: 칩 줄, 큰 숫자 카드(최저임금), 이름-값 줄 목록(공제), 방법 카드, 사기 신호 카드, 3단 칸, 체크리스트.
- 섹션 바로가기용 짧은 이름(`jobsSections[].label`)을 데이터에 추가. H2 제목은 그대로.
- 새 디자인에서 뺀 것: 연락처 카드·권리 소제목 앞 이모지(🏭👷⚖️🇲🇳💰🚫), 사기 신호의 🚩(→ Lucide 깃발 아이콘), 소제목 끝 콜론. 데이터의 `emoji`·`icon` 필드는 옛 화면용으로 남아 있음(다른 곳에서 안 씀).
- 새 부품은 `GuideCParts.jsx` + `guideCParts.module.css`, 체크리스트는 `GuideCCheckList.jsx`로 나눔(틀 기본 파일 길이 때문). 기본 CSS에서 바꾼 규칙: `.section > .subTitle:first-of-type` → `.sectionTitle + .subTitle`(/jobs에서 표 바로 뒤 소제목 위 여백이 0이 되던 문제), `.noteBody p + p` 간격 추가 — /topik은 해당 자리가 없어 화면 변화 없음.

## 그대로인 것
- 주소 `/jobs`, 검색 제목·설명(`src/app/jobs/layout.jsx` — 수정 안 함), H1(`jobsMeta.title`), 본문 데이터(`src/data/guides/jobs.js` — `label`만 추가), 섹션 주소(#jobs-salary 등), H2 제목 문구.
- 구조화 데이터: BreadcrumbJsonLd, HowToJsonLd(임금체불 단계).
- 측정: 자체 조회수 `GuideViewTracker guideId="jobs"`(analytics_events `guide_view`/`jobs`) — 그대로 둔다.
- 관련 팁 4개(RelatedTips), 신고·후원·공유·이전/다음.
