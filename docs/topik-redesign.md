- 홈 변경과 다른 배포로 올린다(홈 변경과 같은 배포에 섞지 않음 — 서로 다른 페이지라 같은 날이어도 각자의 숫자로 본다, 원칙 문서 §2).
- 푸시 일시(한국 시간): 2026-10-26 17:52 — 홈 개편 커밋(00dc42e)과 따로 푸시(별도 배포). 배포는 사용자.
- 관찰: 디자인 변경 1~2주 + 노출·클릭 2~4주. 대조군: 바꾸지 않은 가이드(/visa, /money 등).
- 2026-10-27: 대조군 /visa 본문에 사실 수정이 들어감(한국 비자 접수처를 서울 몽골대사관 → 울란바토르 KVAC·주몽골 한국대사관으로, E-9 단계 순서·설명). 판정 때 /visa는 참고만 하고 /money를 주 대조군으로 본다.
- 2026-10-27 추가: 사용자 결정으로 나머지 가이드 8개도 새 디자인·사실 수정, /money도 사실 수정(디자인은 그대로) — `docs/guides-redesign.md`. 그래서 바뀌지 않은 대조군이 남지 않는다. /topik 판정은 /topik 자신의 기준선 대비 추세와 사이트 전체 노출 추세로 본다(/money는 디자인만 그대로인 약한 대조군).
