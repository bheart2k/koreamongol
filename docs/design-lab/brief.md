## 0. 사용자 지시 (위반 금지)

- 이미지는 **Codex(`image_gen`)**, 영상은 **Codex 이미지 → Grok(`reference_to_video`)** 으로 만든다.
- **SVG·도형·CSS 그림으로 이미지/일러스트를 대체하지 않는다.** (코드는 모션·전환·타이포·셰이더 효과 용도로만)
- 기존 곰 캐릭터(마자알라이)는 쓰지 않는다.
- 단순한 페이드인 수준의 모션으로 끝내지 않는다. 연출된(choreographed) 모션이어야 한다.

## 2. 시안 3종

세 시안은 스타일 변형이 아니라 **컨셉·아트 디렉션·모션 언어가 모두 다른** 안이다. 사용자가 실제로 고를 수 있어야 한다.

### 시안 A — 「같은 하늘 아래」 (Cinematic Sky Journey)

- **핵심 통찰**: 몽골은 "Мөнх хөх тэнгэр(영원한 푸른 하늘)"의 나라. 서울의 사용자는 고향 가족과 같은 하늘 아래 있다. 하늘이 두 나라를 잇는 하나의 캔버스.
- **시그니처**: 스크롤 = 하루의 흐름. 초원의 새벽 → 서울의 낮 → 노을 → 밤의 별. 페이지 전체 배경·강조색이 스크롤에 따라 보간된다 (Gold = 초원의 해, Navy = 서울의 블루아워).
- **아트 디렉션**: 국가 관광 캠페인 영화의 스틸. 시네마틱 실사, 아나모픽 렌즈감, 옅은 헤이즈, 골든아워/블루아워. 색보정: 하이라이트 금빛, 섀도 딥네이비, 중간톤 저채도, 필름 그레인.
- **키비주얼 (Codex, 데스크톱 16:9 + 모바일 9:16 각각)**
  - K1 새벽 초원: 게르와 굴뚝 연기, 먼 산, 말 실루엣, 막 떠오르는 해
  - K2 일출의 운해 (구름 위)
  - K3 블루아워 서울: 한강, 다리 조명, 스카이라인
  - K4 서울 야경 → K5 은하수 아래 초원의 게르 (마무리)
  - 챕터 6장: 오기 전 / 도착(공항 도착장 아침빛) / 생활(노을 진 주택가 골목, 따뜻한 창) / 일(아침 산업현장, 존엄하게) / 말과 문화(시장·카페 거리) / 사람들(한강 노을, 뒷모습)
- **영상 (Grok)**: V1 K1→K2 카메라 상승, V2 K2→K3 구름 뚫고 하강 (첫/끝 프레임 고정), 챕터 루프 6개 (첫=끝 프레임), V3 K4→K5 (도시 불빛이 별이 됨)
- **모션 연출**
  - 히어로: 화면 고정(약 300vh) + **캔버스 프레임 시퀀스 스크럽**(V1+V2). 서울 착지 순간 H1과 "지금 필요한 것" 퀵메뉴가 유리 패널로 등장.
  - 챕터: 데스크톱 가로 스크롤 고정 트랙, 패널 간 WebGL 디스플레이스먼트 전환 (또는 clip-path 와이프). 각 패널은 풀블리드 루프 영상 + 큰 챕터 번호 + 해당 가이드 링크 목록. 모바일은 세로로 쌓이는 풀스크린 카드 스택.
  - 환율: 숫자 롤링 카운터. 마무리: V3 스크럽 → 커뮤니티·후원 CTA.
  - 긴급번호: 화면 하단 고정 플로팅 버튼 (탭하면 119/112/1345 펼침).
- **챕터 ↔ 가이드 매핑**: 오기 전(visa, topik) / 도착(arrival, transport, apps) / 생활(housing, hospital, money, exchange) / 일(jobs, severance) / 말과 문화(korean-life, tips) / 사람들(community, emergency는 플로팅)

### 시안 B — 「두 개의 고향」 (Editorial Duality)

- **핵심 통찰**: 몽골과 한국은 서로 운율을 이루는 장면을 가지고 있다. 두 문화를 나란히 놓아 각자의 아름다움을 존중하는 방식으로 자긍심을 만든다.
- **아트 디렉션**: Kinfolk·Monocle·Cereal 급 하이엔드 에디토리얼 사진. 자연광, 넓은 여백, 촉감 있는 재질, 저채도. 짝을 이루는 이미지(diptych):
  - 게르 천창(тооно)을 올려다본 구도 ↔ 한옥 처마를 올려다본 구도
  - 펠트 질감 ↔ 한지 창호
  - 초원의 지평선 ↔ 한강의 수평선
  - 수테차 그릇의 김 ↔ 한국 찻사발의 김
  - 델(deel) 원단 클로즈업 ↔ 한복 원단 클로즈업 (의상 전체 착용 모습은 피한다)
- **팔레트**: 종이 오프화이트, 잉크 네이비, 금박 포인트, 테라코타 소량.
- **타이포 주도 레이아웃**: 초대형 디스플레이 타이포(뷰포트 폭 기준), 번호 매긴 섹션(01–06), 작은 캡션, 비대칭 12컬럼 그리드. 키릴 지원 디스플레이 세리프를 쓰려면 **Cyrillic 서브셋 지원을 확인한 폰트만** 사용.
- **영상 (Grok)**: 시네마그래프 — 이미지 대부분은 정지, 한 요소만 움직이는 6초 루프 (게르 연기, 찻김, 강물 잔물결, 바람에 흔들리는 천).
- **모션 연출**
  - 히어로: 좌(몽골)·우(한국) 딥틱이 스크롤에 따라 중앙으로 밀려와 **한 장의 이미지로 합쳐짐** (두 고향이 하나로). 대형 헤드라인은 스크롤 속도에 따라 기울기/스케일 반응.
  - 가이드 목록: 대형 타이포 행 리스트. 데스크톱은 hover 시 커서를 따라오는 이미지 프리뷰(WebGL 물결 왜곡), 모바일은 행이 펼쳐지며 이미지 노출.
  - 섹션 등장: clip-path inset 와이프, 이미지 1.2→1.0 스케일, 괘선 드로잉.
  - 상황별 바로가기: 스크롤 속도에 반응하는 마키 띠.
  - 환율: 대형 에디토리얼 숫자 + 오도미터 애니메이션.

### 시안 C — 「살아있는 지도」 (Living Diorama)

- **핵심 통찰**: 새로 온 사람에게 한국 생활은 낯선 동네의 지도다. 홈 자체를 탐험 가능한 미니어처 세계로 만들고, 가이드는 그 안의 장소가 된다.
- **아트 디렉션**: 프리미엄 3D 미니어처(틸트시프트 디오라마). 부드러운 GI 조명, 매트 클레이 + 유리 재질, 브랜드 파생 파스텔(크림, 스카이, 네이비, 골드). 유치한 카툰 금지. 고급 3D 일러스트 수준.
- **세계관**: 떠 있는 섬 디오라마. 한쪽은 서울 동네(아파트, 지하철 입구, 병원, 은행, 편의점, 버스정류장, 공장, 학교), 비행 항로로 이어진 작은 몽골 초원 섬(게르, 말).
- **영상 (Grok)**: 전경 → 푸시인 카메라 플라이스루, 장소별 클로즈업 루프 (작은 사람들, 버스 이동, 깜빡이는 불빛).
- **모션 연출**
  - 히어로: 플라이스루 스크럽 → 정착하면 건물 위에 **핫스팟 핀**(HTML 오버레이, % 좌표) 등장. 핀 hover/탭 → 가이드 카드 팝업. 마우스/자이로 기반 미세 틸트 패럴랙스.
  - 장소별 섹션: 클로즈업 렌더 + 루프 영상이 좌우 교차 배치.
  - 낮/밤: 다크모드에서 밤 버전 디오라마(Codex 야간 변형)로 크로스페이드.
  - 마이크로 인터랙션: 마그네틱 버튼, 스프링 카드.

## 3. 공통 품질 기준

### 이미지·영상 제작 규칙
- 시안마다 **기준 룩 프레임 1장을 먼저 만들고**, 나머지는 그 이미지를 레퍼런스로 파생한다 (톤 일관성).
- 금지: 이미지 속 글자·로고·워터마크, 국기·소욤보·태극 등 국가 상징, 민속 의상 캐리커처.
- 인물은 원경·뒷모습·실루엣 위주 (AI 얼굴 어색함·고정관념 회피).
- 실존 랜드마크(남산타워 등)는 형태 왜곡을 육안 검수. 이상하면 다시 생성하거나 뺀다.
- 생성한 이미지는 반드시 직접 열어 보고 품질을 판단한다. 마음에 안 들면 다시 만든다. **"이 정도면 되겠지" 금지.**
- 프롬프트 기록: `docs/design-lab/prompts/{a|b|c}.md`
- 원본(PNG/MP4): `.design-lab-src/{a|b|c}/` (git 제외). 웹용: `public/design-lab/{a|b|c}/` (이미지 WebP, 영상 MP4 H.264 + 포스터).
- Grok 영상은 720p 상한. 첫/끝 프레임 이미지의 비율과 `aspect_ratio`를 일치시킨다. 생성 후 첫/끝 프레임을 추출해 실제로 움직였는지 확인한다.

### 구현 규칙
- `page.jsx`는 서버 컴포넌트 (`'use client'` 금지). 모션은 같은 폴더의 클라이언트 컴포넌트로 분리. 모든 텍스트·링크는 DOM에 존재.
- 라이브러리: `gsap`(ScrollTrigger, SplitText, Flip 등 전 플러그인 무료), `lenis`, `ogl`(WebGL). 추가 패키지가 필요하면 직접 설치하지 말고 PM에게 요청.
- 히어로 스크롤 영상은 `<video>` currentTime 방식 대신 **캔버스 프레임 시퀀스**.
- 색은 CSS 변수 토큰으로. 높이는 `min-h-content`/`h-content` 우선.
- 300줄 넘는 파일은 분리.

### 성능·접근성 (실사용자 = 모바일 데이터 쓰는 E-9 노동자 다수)
- 첫 화면: 히어로 첫 프레임을 우선 로딩 `<img>`로 즉시 표시. H1은 JS 없이 첫 페인트에 보여야 함 (등장 효과는 CSS 애니메이션으로).
- 시퀀스·영상은 첫 화면 이후 점진 로딩. `navigator.connection.saveData` 또는 느린 망이면 정지 이미지 + 느린 줌으로 대체.
- 목표 예산: 첫 화면 ≤ 1.5MB / 전체 데스크톱 ≤ 25MB / 모바일 ≤ 10MB. 실측치를 보고.
- 모바일 390px은 9:16 전용 소스로 **따로 아트 디렉션** (단순 크롭 금지).
- `prefers-reduced-motion`: 스크럽·루프 없이 정지 이미지.
- 5초 넘게 자동 재생되는 영상에는 일시정지 버튼 (WCAG 2.2.2).
- 스크롤 중 60fps 목표.

## 4. 검증·보고

- 직접 브라우저로 데스크톱 1440×900, 모바일 390×844에서 확인. 주요 스크롤 지점 스크린샷은 각 세션의 스크래치 폴더에만 저장(프로젝트에 남기지 않음).
- dev 서버는 사용자가 띄운다 (http://localhost:5005). 에이전트는 `pnpm dev`·`pnpm build`를 실행하지 않는다.
- 커밋·푸시 금지.
- 보고 양식: **변경 파일 / 결과 / 미해결 / 사용자 결정 필요** + 에셋 용량 실측 + 원어민 검수 필요 문구 목록.
