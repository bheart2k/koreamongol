# 시안 E 「같은 하늘 아래 · 에센셜」 — 에셋 기록

> 작성: 하늘(시안 A·E 워커) / 2026-10-07
>
> E는 시안 A의 정제판이다. **새 영상·새 이미지를 생성하지 않았다.** 모든 화면 에셋은 A의 public 파일(`/design-lab/a/...`)을 읽기 전용으로 직접 참조한다(복사하지 않음). 생성 프롬프트 원문은 [`a.md`](./a.md)를 본다.

## 재사용한 A 에셋

| 용도 | 파일 (`public/design-lab/a/`) | E에서 쓰는 방식 |
|---|---|---|
| 히어로 첫 화면 | `k1.webp`, `k1-m.webp` | 우선 로딩 포스터 (A와 같음) |
| 히어로 스크럽 | `seq-hero/`, `seq-hero-m/` (V1+V2) | 같은 프레임을 520vh → **200vh**에 매핑, 진행도 70%에서 서울 착지 |
| 착지 대체 이미지 | `k3.webp`, `k3-m.webp` | 시퀀스 미로딩 시 폴백 |
| 챕터 6장 | `c1~c6.webp`, `c1~c6-m.webp` | 일반 스크롤 카드의 정지 이미지 |
| 챕터 루프 | `c1~c6-loop.mp4`, `c1~c6-loop-m.mp4` | **화면에 55% 이상 보이는 카드 1개만** 재생, 첫 재생 때만 내려받음 |
| 마무리 | `k4.webp`, `k5.webp` (+ `-m`) | 시퀀스 대신 정지 이미지 두 장을 스크롤 크로스페이드 (고정 없음) |

A에서 쓰던 `seq-finale/`, `seq-finale-m/`(V3 시퀀스)와 WebGL 챕터 전환은 E에서 쓰지 않는다.
