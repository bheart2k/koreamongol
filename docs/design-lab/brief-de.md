# 시안 D·E 브리프 (design-lab 2차)

> **2026-10-08 갱신:** 웹용 에셋은 R2(`https://cdn.koreamongol.com/design-lab/v1/...`)로 이전했고 `public/design-lab`·`.design-lab-src`는 삭제했다(원본 영상은 R2 `design-lab/originals/`에 보관). 본문의 `public/design-lab/...`·`.design-lab-src/...` 경로는 당시 기록이다. 새 웹용 파일은 프로젝트 밖 임시 폴더(세션 스크래치 등)에서 만들어 `scripts/design-lab/upload-r2.mjs`로 올리고, 코드에서는 `labAsset()`/`LAB_ASSET_BASE`로 참조한다.

> 작성: PM / 2026-10-07
> 공통 기준은 `docs/design-lab/brief.md` 0·3·4절을 그대로 따른다. 이 문서는 D·E에만 해당하는 내용이다.
> 목적: A·C를 보고 나온 사용자 피드백을 반영한 두 방향을 만들어, 실제 사람들 의견을 듣고 최종안을 정한다.

## 사용자 피드백 (출발점)

- **A**: 가장 멋있다. 하지만 모든 섹션이 긴 스크롤 연출이라 지치고, 정작 정보를 찾기 어렵다. 영상이 남발된다. 히어로 연출은 좋았다.
- **C**: 목적에 가장 충실하다. 핵심 정보를 보기 편하다. 하지만 이미지가 장난감 같다.
- **B**: 참고용으로 보관, 종료.

## 이번 라운드 제약 (위반 금지)

- **새 영상 생성 금지.** Grok·젠스파크 등 영상 생성 도구를 쓰지 않는다. 기존 영상(A·C의 public 에셋)을 재사용하거나, Codex 이미지만 추가한다.
- SVG·도형으로 이미지를 대체하지 않는다. 움직임은 코드(GSAP·CSS·WebGL)로 만들되, 그림은 Codex 래스터 이미지다.
- **정보 접근성 기준**: 데스크톱 첫 화면에서 스크롤 1~2번 안에 '지금 필요한 것' 바로가기와 가이드 목록에 닿아야 한다. 화면 고정(pin) 스크롤 연출은 히어로 1곳만 허용한다.
- 페이지 전체 높이를 보고에 포함한다(데스크톱 1440×900, 모바일 390×844 기준 뷰포트 몇 개 분량인지).
- **dev 서버를 깨뜨리지 않는다.** 모든 워커와 사용자가 같은 dev 서버를 본다. 한 파일의 빌드 에러(없는 모듈 import, CSS 중괄호 누락 등)가 사이트 전체 페이지를 막는다. 새 모듈은 파일을 먼저 만든 뒤 import하고, CSS는 저장할 때마다 중괄호 짝을 확인하며, 큰 개편은 새 파일에서 완성한 뒤 한 번에 교체한다.

## 시안 D — 「전시된 두 고향」 (Architectural Maquette)

**한 줄**: C의 구조(지도 핀 내비게이션, 정보 중심 레이아웃)는 그대로 두고, 그림을 장난감 디오라마에서 **건축가의 프레젠테이션 모형**으로 격상한다.

### 아트 디렉션
- 박물관이나 건축 전시에 놓인 정교한 축척 모형. 무광 화이트·크림 석고와 종이(바스우드) 재질, 밝은 오크 원목 받침대, 브러시드 브라스(골드) 포인트, 물은 반투명 네이비 아크릴.
- 조명: 갤러리 조명. 키라이트 하나, 길고 부드러운 그림자, 얕은 피사계심도, 배경은 따뜻한 오프화이트 또는 깊은 네이비 전시 벽.
- 채도를 낮게 유지하고, 색은 네이비·골드·테라코타 포인트에만 쓴다. 장난감 느낌의 원색, 동글동글한 클레이 형태는 금지한다.
- 구성: 오크 받침대 위에 놓인 **서울 동네 모형**과 **몽골 초원 모형**, 두 모형을 잇는 가는 **브라스 와이어 아치**(비행 항로를 물리적 조형물로 표현, 작은 브라스 비행기 하나가 아치 위에 고정). 두 모형은 대등한 크기다.
- 몽골 모형: 나무가 거의 없는 완만한 초원 구릉, 흰 펠트 질감 게르, 브라스 미니어처 말, 굽이 강(아크릴). 알프스처럼 보이는 설산과 숲은 금지한다.
- 서울 모형: C와 같은 장소 구성(주거·병원·은행·편의점·지하철·버스·공장·학교·공항·한옥). 형태만으로 구분되게 하고, 글자·기호는 넣지 않는다.

### 구성과 모션 (영상 없음)
- **히어로**(유일한 고정 구간, 최대 150vh): 전시 모형 전경 2K 이미지. 스크롤하면 코드로 카메라 돌리 효과를 냅니다(스케일·이동 + 같은 각도의 근접 이미지로 크로스페이드). 안착하면 건물 위에 핫스팟 핀이 순서대로 등장하고, 핀을 누르면 가이드 카드가 뜹니다. 마우스·자이로로 미세 틸트 패럴랙스를 줍니다.
- 히어로 바로 아래: '지금 필요한 것' 바로가기, 긴급번호 띠.
- **전시실 Room 01–06**: 챕터마다 모형의 해당 부분 클로즈업(Codex)과 해당 가이드 링크 목록. 고정 스크롤 없이 일반 스크롤로 흐르게 하고, 등장 효과(clip-path 와이프, 이미지 스케일, 그림자 이동)만 줍니다.
- 최근 업데이트, 환율, 소개, 커뮤니티·후원.
- 다크모드: 같은 모형을 야간 전시 조명(스포트라이트, 창문 불빛)으로 바꾼 변형 이미지로 크로스페이드.

### 시작점
- C의 코드(`src/app/design-lab/c/**`)를 **읽어서** D 폴더로 복사한 뒤 수정하세요. C 파일은 수정하지 않습니다. 핀 좌표는 D 최종 이미지에 맞춰 다시 잡습니다.
- C의 영상(장난감 스타일)은 D 톤과 맞지 않으니 쓰지 않습니다.

## 시안 E — 「같은 하늘 아래 · 에센셜」 (A 정제판)

**한 줄**: A의 시네마틱 히어로와 '하루의 흐름' 컨셉은 살리고, 히어로 이후는 **정보를 빠르게 찾는 홈**으로 재구성한다.

### 유지
- A의 아트(시네마틱 실사, 금빛·네이비 색보정, 필름 그레인)와 기존 에셋 전부(`public/design-lab/a/**`를 **읽기 전용으로 직접 참조**, 복사하지 않음).
- 히어로 스크럽 시퀀스(V1+V2), 서울 착지 시 H1과 유리 패널 퀵메뉴.

### 바꿀 것
1. **히어로 길이**: 520vh → 최대 200vh. 같은 프레임 시퀀스를 더 짧은 스크롤에 매핑하고, 퀵메뉴가 더 빨리 나타나게 합니다.
2. **히어로 이후는 고정 스크롤 없음.** 챕터 가로 트랙(고정 + WebGL 전환)을 없애고, 6개 챕터를 일반 스크롤 섹션으로 만듭니다. 각 챕터는 정지 이미지(기존 포스터·키비주얼)와 가이드 링크 목록을 한눈에 보여줍니다.
3. **영상 절제**: 루프 영상은 **화면에 보이는 챕터 1개만** 재생합니다(나머지는 포스터 정지 이미지). 동시에 재생되는 영상은 최대 1개로 합니다.
4. **빠른 찾기 바**: 히어로가 끝나면 상단에 챕터 칩 바가 고정됩니다(오기 전·도착·생활·일·말과 문화·사람들). 칩을 누르면 해당 섹션으로 이동하고, 현재 위치를 표시합니다. 사이트 Navbar(4rem) 바로 아래에 붙입니다.
5. **가이드 14개 전체 목록**을 챕터와 별개로 한 화면에 볼 수 있게 둡니다(검색하듯 훑을 수 있는 밀도 높은 그리드).
6. **배경 하루 흐름**: 유지하되 은은하게.
7. **피날레**(V3 스크럽): 고정하지 말고 일반 스크롤 안에서 짧게(정지 이미지 + 크로스페이드로 대체해도 됩니다).

### 목표 수치
- 데스크톱 전체 페이지 높이가 A의 절반 이하일 것. A와 E의 실측 높이를 함께 보고합니다.
- 히어로 시작 후 스크롤 2번 안에 퀵메뉴 도달.
