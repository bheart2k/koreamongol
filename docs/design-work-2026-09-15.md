# 2026-09-15 디자인 개선 작업 기록

## 확정 방향

- 기준 캐릭터는 L 색연필형 마자알라이. 자연스러운 곰의 얼굴, 비교적 얄상한 체형, 금갈색 털과 남색 크로스백을 유지한다.
- L은 고정 이미지가 아닌 캐릭터다. 새 페이지에는 상황에 맞는 포즈·각도·구도를 새로 제작한다. 동일 전신 이미지의 반복 배치를 기본값으로 삼지 않는다.
- 남색 #1B2D4F와 하늘색 #E8F0FE를 정보·탐색 영역에 사용하고, 아이보리 #FAF6F0와 손그림으로 온기를 더한다. 주요 행동은 테라코타로 강조한다.
- 이미지의 사각 경계가 드러나지 않게 한다. 풍경은 가장자리를 자연스럽게 페이드 처리하고, 개별 캐릭터는 실제 PNG 투명 배경으로 적용한다.
- 몽골어 정보와 몽골 사용자를 중심에 둔다. 문화적 판단 근거와 해석 한계는 koreamongol-design-guide.html의 확정 디자인 방향에 기록되어 있다.
- 이미지 생성만으로 완료하지 않는다. 프로젝트 자산 저장, 페이지 참조 연결, 허용된 정적 확인까지 수행하고 확인 링크를 제공한다.

## 구현과 자산

- 공통 안내 화면: src/components/guide/IllustratedGuide.jsx 및 IllustratedGuide.module.css.
- 질문·계산기 화면: src/components/guide/SupportHeader.jsx 및 SupportPages.module.css.
- 메인·입국·비자·헤더와 일부 화면은 전용 CSS 모듈을 사용한다.
- 기준 캐릭터 및 비교 시안: public/images/mascot-preview/.
- 메인 풍경·초기 안내 삽화: public/images/home/.
- 페이지별 캐릭터 PNG 및 생성 프롬프트: public/images/guides/.
- 개별 포즈는 내장 image_gen 도구로 기준 L을 참조하여 생성했다. 비교용 시안과 생성 기록도 함께 보존한다.
- 빠른 답변 상세 /tips/[slug]는 이번 목록 화면 개선에 포함하지 않았다.

## 검증 및 제한

- 각 작업 묶음에서 변경 JSX의 SWC 문법 검사, CSS의 PostCSS 구문 검사, 클래스 참조와 자산 경로 등 정적 확인을 수행했다.
- 신규 캐릭터 PNG의 알파 채널과 투명 모서리를 확인했다. 주요 바로가기의 대상 ID를 확인했다.
- 계산기 입력의 label과 input ID를 연결했다. 환율 조회 및 계산식·상태 처리 코드는 변경하지 않았다.
- 안내 데이터, 의료·비자·노동 정보의 최신성 재검증은 이번 디자인 작업 범위가 아니다.
- 전체 빌드, 개발 서버 실행·재시작, HTTP 요청 및 브라우저 검증은 실행하지 않았다. 실제 모바일·다크모드·상호작용의 화면 검증은 남아 있다.
